# C-sandbox

A playground for C code — buildable and runnable on Windows.

## Status

Early stage. Agent manifest lives in [`.agents/`](.agents/) (start at [`AGENTS.md`](AGENTS.md)).
Includes `src/hello.c` — build and run via [`.agents/guides/commands.md`](.agents/guides/commands.md).

## Quick start

1. Install MinGW-w64 `gcc` and ensure it is on `PATH`.
2. Follow [`.agents/guides/setup.md`](.agents/guides/setup.md).
3. Build and run: `.\build.ps1` then `.\build.ps1 run hello` — see [`.agents/guides/commands.md`](.agents/guides/commands.md).
